## Manufacturing System
Manufacturing System คือ ระบบที่ใช้บริหารจัดการกระบวนการผลิตในโรงงาน ตั้งแต่การวางแผนการผลิต การจัดการวัตถุดิบ การควบคุมเครื่องจักร การติดตามการผลิต ไปจนถึงการตรวจสอบคุณภาพและสรุปผลการผลิต

พูดง่าย ๆ คือ ระบบที่ช่วยให้โรงงานควบคุมและติดตามกระบวนการผลิตทั้งหมดได้อย่างเป็นระบบ

## วัตถุประสงค์
- บริหารจัดการกระบวนการผลิต ให้เป็นระบบและมีประสิทธิภาพ
- วางแผนและติดตามการผลิต ให้สามารถผลิตสินค้าได้ตามกำหนดเวลา
- จัดการวัตถุดิบและสินค้าคงคลัง ให้มีปริมาณเพียงพอต่อการผลิต
- ลดต้นทุนการผลิต และลดการสูญเสียของวัตถุดิบ
- ติดตามสถานะเครื่องจักร และลดปัญหาการหยุดทำงาน
- ควบคุมและตรวจสอบคุณภาพสินค้า ให้เป็นไปตามมาตรฐาน
- เก็บข้อมูลการผลิต เพื่อใช้วิเคราะห์และประเมินประสิทธิภาพ
- ลดความผิดพลาดจากการทำงานด้วยมือ และลดการใช้เอกสาร
- ช่วยในการตัดสินใจ โดยนำข้อมูลการผลิตมาแสดงในรูปแบบรายงานหรือ Dashboard
- เพิ่มประสิทธิภาพโดยรวมของโรงงาน และช่วยให้สามารถตอบสนองความต้องการของลูกค้าได้ดีขึ้น

    npm i
    เพิ่ม .env
    เปิด docker desktop
    docker compose up -d
    npx prisma migrate dev
    npx prisma generate
    npm run dev
